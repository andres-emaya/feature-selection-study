Comparison of supervised feature selection techniques (filter, wrapper and intrinsic methods) on categorical and numerical datasets.

**Methods:** Chi-Squared, Mutual Information, ANOVA F-test, RFE, Permutation Importance, Model Coefficients

**Datasets:** Mushroom (categorical) and Water Quality (numerical)

**Built with:** Python, pandas, scikit-learn, Matplotlib
